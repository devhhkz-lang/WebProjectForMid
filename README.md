# Foodly — Online Food Ordering (Web Programming project, topic №13)

Menu → cart → checkout. Pure HTML / CSS / JavaScript, no build step. Data lives in `localStorage` (see `js/storage.js`).

## Run
Open `index.html` (or serve the folder: `python3 -m http.server`).
